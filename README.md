# Hamburgueria (PHP + MySQL)

Site de uma hamburgueria que fizemos em grupo. O HTML, o CSS e a base do projeto vêm do repositório do pedro-kalili-07 (https://github.com/pedro-kalili-07/Hamburgueria), com ajuda do RicMTH. Nessa versão eu fiz toda a parte do banco de dados.

O cardápio agora vem do MySQL, o pedido fica salvo no banco e também vai pro WhatsApp. Tem um painel admin pra cadastrar, editar e excluir produto e ver os últimos pedidos.

Feito com PHP, MySQL e JavaScript (o HTML e o Tailwind são do projeto original).

Pra rodar precisa de PHP e MySQL. Copia o conexao.example.php pra conexao.php e coloca os dados do seu banco. As pastas assets e styles ficam no repositório original, aqui só tem o PHP e o JavaScript.

Ainda falta colocar login no painel admin, hoje qualquer um com o link consegue mexer nos produtos.
